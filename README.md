# AI-редактор

Текстовый редактор с AI-ассистентом: выделяете фрагмент или пишете с нуля — ассистент
переписывает текст по литературной норме, сокращает его и показывает метрики в реальном
времени: воду, читаемость, тошноту и оценку по шкале «Главреда».

**Демо:** https://ai-editor-assistant.vercel.app — работает без ключа, в демонстрационном
режиме.

![Главный экран](docs/screenshots/01-idle.png)

## Возможности

- **Улучшить** — литературная правка: орфография, пунктуация, типографика, замена
  канцелярита и разговорных слов, удаление слов-сорняков. Результат доводится до
  метрик: вода ≤ 10%, тошнота ≤ 10%, читаемость > 70.
- **Сократить** — текст становится короче: убираются вода, штампы, повторы и
  второстепенные части, смысл сохраняется. Вода и тошнота доводятся до ≤ 5%.
- **Стриминг ответа** — текст появляется по словам, а не через 10 секунд ожидания.
- **Сравнение до/после** — после AI-правки исходник и результат доступны рядом,
  с количеством слов и их разницей.
- **Отмена** — запрос обрывается на полуслове, полученное сохраняется.
- **Понятные ошибки** — неверный ключ, лимит запросов, таймаут, пустой ответ: у каждой
  ошибки своё сообщение и подсказка.
- **Проверка орфографии и грамматики** — ошибки подсвечиваются прямо в тексте,
  есть переход по ним, фильтры по типам (орфография, пунктуация, грамматика, стиль),
  счётчик ошибок на 100 слов и кнопка «Применить безопасные».
- **Исправление в один клик** — любая найденная ошибка применяется одной кнопкой,
  без ручного поиска места в тексте.
- **Свой словарь** — слова, которые не нужно считать ошибками (термины, названия),
  добавляются в один клик и запоминаются в браузере.
- **Загрузка файлов** — перетащите `.txt`, `.md`, `.docx` или PDF в редактор
  или выберите файл кнопкой «Файл». Текст из PDF извлекается локально в браузере
  без OCR.
- **Повторы слов** — самое частое слово заменяется синонимом в один клик,
  «тошнота» падает сразу.
- **История версий** — каждое исправление и вставка сохраняются в истории,
  историю можно восстановить после перезапуска браузера и сравнить с текущей версией.
- **Ссылки на правила** — для замечаний LanguageTool доступна карточка правила
  в публичной библиотеке сервиса.
- **Строгость проверки** — режимы «мягко», «строго» и «только ошибки».
- **Личная статистика** — число проверок, найденных замечаний, принятых правок
  и время последней проверки; данные сохраняются локально в браузере.
- **Светлая и тёмная темы** — выбор сохраняется локально.
- **Метрики текста** — символы, слова, вода, читаемость, тошнота, время чтения, оценка
  «Главреда»; обновляются при каждом изменении текста.
- **Черновик сохраняется** — текст не теряется при обновлении страницы.
- **Экспорт** — готовый текст скачивается как `.txt` или `.docx`, а PDF
  формируется через системное окно печати браузера.
- **Горячие клавиши** — `Ctrl + Enter` запуск, `Esc` отмена.
- **Мобильная версия** — панель ассистента выезжает снизу.

## Технологии

Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS · Zustand · OpenAI API

## Запуск на Windows

Нужен Node.js 20 или новее.

```powershell
cd ai-editor-assistant
npm install
Copy-Item .env.local.example .env.local
npm run dev
```

Откройте http://localhost:3000

### Настройки

Файл `.env.local`:

```
OPENAI_API_KEY=sk-...   # ключ OpenAI
OPENAI_MODEL=gpt-4o-mini
AI_MOCK=1               # демо-режим без ключа
LANGUAGETOOL_URL=http://localhost:8010/v2/check  # необязательно: свой LanguageTool
```

`AI_MOCK=1` включает демонстрационный режим: текст обрабатывается встроенными правилами,
ключ не нужен, запросы в интернет не уходят. Уберите эту строку и укажите ключ, чтобы
работала настоящая модель.

## Ограничения проверки

- Проверка текста — до 50 000 знаков за один запрос; сервер проверяет документ
  частями по 5000 знаков.
- Поддерживаются текстовые PDF размером до 5 МБ; сканы без текстового слоя
  требуют OCR и не распознаются.
- Не больше 20 проверок за 10 минут с одного адреса (настраивается переменной
  `CHECK_RATE_LIMIT`).
- Одинаковые тексты кешируются на 5 минут — повторная проверка не тратит лимит.
- По умолчанию текст отправляется в публичный LanguageTool. Чтобы обрабатывать
  его на своём экземпляре, задайте `LANGUAGETOOL_URL` с адресом его `/v2/check`.
- Если LanguageTool недоступен, включаются встроенные правила. При нескольких
  экземплярах приложения лимиты и кеш пока хранятся в памяти каждого процесса.

Черновик, история, словарь, тема и статистика хранятся в `localStorage` текущего
браузера: это не облачная синхронизация и не резервное копирование аккаунта.
PDF импортируется локально в браузере и экспортируется через системную печать;
облачная синхронизация и распознавание сканов пока не поддерживаются.

## Деплой на Vercel

1. Загрузите проект в GitHub.
2. Откройте [vercel.com/new](https://vercel.com/new) и выберите репозиторий.
3. В настройках проекта добавьте `OPENAI_API_KEY` (или `AI_MOCK=1` для демо).
4. Нажмите Deploy.

Каждый `git push` после этого собирается автоматически.

## Публикация через GitHub Pages

GitHub Pages размещает статический интерфейс. Рабочие AI- и проверки API остаются
на существующем Vercel-деплое `https://ai-editor-assistant.vercel.app`; Pages
обращается к нему по HTTPS. Сервер разрешает API-запросы с origin
`https://goviks.github.io`. Текст, отправленный на AI-обработку или проверку,
передаётся этому Vercel API так же, как при использовании основного сайта.

Workflow `.github/workflows/pages.yml` собирает отдельный Vite frontend и
публикует его в GitHub Pages при push в `main`. После первого успешного запуска
сайт доступен по адресу
https://goviks.github.io/ai-editor-assistant/.

## Локальная сборка Pages

```powershell
$env:GITHUB_PAGES = "true"
$env:NEXT_PUBLIC_API_BASE_URL = "https://ai-editor-assistant.vercel.app"
$env:NEXT_PUBLIC_PDF_WORKER_URL = "/ai-editor-assistant/pdf.worker.min.mjs"
npm run pages:build
```

Статические файлы появятся в `out/`. Для работы API нужен доступный Vercel backend;
сборка Pages сама по себе серверные API-маршруты не размещает.
